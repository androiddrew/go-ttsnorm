# go-ttsnorm

`github.com/androiddrew/go-ttsnorm` turns written English into text a
text-to-speech model can read aloud. It has no native dependencies.

| Package | Does |
|---|---|
| `normalize` | Numbers, years, ordinals, dates, clock times, money, percents, units, versions, ranges, titles and abbreviations become words; URLs and emails are spelled out |
| `markdown` | Turns markdown (as in chat replies) into plain prose and drops emoji |
| `sentence` | Splits text into sentence-sized chunks for streaming synthesis |
| `corpus` | The 476-input test corpus with the Python reference output and reviewed deviations |

```go
// KittenTTS: drop symbols the model can't read.
text := normalize.Text(markdown.ToSpeech(input))
// Kokoro/Misaki: keep punctuation and inline pronunciation overrides.
text = normalize.Text(markdown.ToSpeech(input, markdown.KeepOverrides()),
	normalize.KeepPunctuation(), normalize.UpperLetters(), normalize.ProtectOverrides())
for _, chunk := range sentence.Split(text) { /* synthesize */ }
```

`normalize` is a port of KittenTTS's `normalize_text`. With no options its output
matches the Python reference for every input in `corpus/normalize_corpus.txt`,
apart from the reviewed deviations in `corpus/normalize_overrides.yaml`.
`normalize_golden.json` is generated by `make golden` in
[gokittentts](https://github.com/androiddrew/gokittentts), which keeps the
Python reference scripts; copy it here after regenerating.

- `KeepPunctuation()` keeps quotes, apostrophes, brackets and other symbols that the
  default output replaces with spaces, for phonemizers that use them.
- `UpperLetters()` spells URLs, emails and `AM`/`PM` in capitals, which Misaki reads
  as letter names (in lower case it reads `a` as the article).
- `ProtectOverrides()` leaves Misaki overrides such as `[Kubernetes](/kˌubəɹnˈɛtiz/)`
  or `[read](-1)` untouched and normalizes only the text between them.
- `markdown.KeepOverrides()` keeps those overrides as written; otherwise a link is
  read as its text.

`sentence.Split` uses chunks of at most 400 characters and splits a first chunk
over 120 characters at its first comma, so streamed audio starts sooner.
`sentence.Splitter` changes both lengths.

`go test ./...` runs everything. `scripts/gen_emoji_table.py` regenerates
`markdown/emoji_table.go`.
